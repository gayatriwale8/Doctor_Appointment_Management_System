# Doctor Appointment Management System

A beginner-friendly Doctor Appointment Management System developed using Python.

## Features

- Login System
- Home / Dashboard
- Add Appointment
- View Appointments
- Search Appointment
- Update Appointment
- Delete Appointment
- Logout
- Excel data storage

## Technologies Used

- Python
- Tkinter
- OpenPyXL
- Microsoft Excel

## Project Flow

Login → Home → Add → View → Search → Update → Delete → Logout

## Data Storage

Appointment records are stored in an Excel file using OpenPyXL.

## Purpose

This project was developed to practice Python programming, GUI development, functions, and Excel data management.
